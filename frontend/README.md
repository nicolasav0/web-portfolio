# 🎨 Frontend

Frontend application for my personal portfolio, built with **Vue 3** and **Vite**.

This application is responsible for presenting my projects, skills, and professional information through a responsive and modern user interface.

---

## 🛠️ Tech Stack

- Vue 3
- Vite
- Vue Router
- HTML5
- CSS3

---

## 📂 Project Structure

```text
src/
├── assets/
├── components/
├── layouts/
├── router/
├── styles/
├── utils/
├── views/
├── App.vue
└── main.js
```

---

## 🚀 Getting Started

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

---

## 📜 Available Scripts

| Command | Description |
|----------|-------------|
| `npm run dev` | Starts the development server |
| `npm run build` | Builds the application for production |
| `npm run preview` | Serves the production build locally |
| `npm run lint` | Runs ESLint |
