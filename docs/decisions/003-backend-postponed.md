# ADR-0003 - Postpone Backend Development

## Status

Accepted

## Context

The long-term architecture includes a Spring Boot backend.

## Decision

Development will begin with a frontend-only implementation.

The backend will be introduced in a later phase.

## Rationale

- Prioritize UI and portfolio presentation.
- Iterate faster.
- Introduce backend features only when they provide real value.

## Consequences

The frontend will initially serve static content.
