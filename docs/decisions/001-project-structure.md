# ADR-0001 - Project Structure

## Status

Accepted

## Context

Although the project currently consists only of a frontend application, a backend is planned for future iterations.

## Decision

The repository will be organized as:

- /frontend
- /backend
- /docs

The backend directory will remain empty until implementation begins.

## Consequences

### Positive

- No repository restructuring later.
- Clear separation of concerns.
- Easier transition to a full-stack project.

### Negative

- Slightly more structure than currently required.
