# ADR-0002 - Use Vue.js

## Status

Accepted

## Context

A frontend framework is required to build a responsive and maintainable portfolio.

## Decision

Vue.js was selected together with Vite.

## Rationale

- Component-based architecture.
- Excellent developer experience.
- Fast build times with Vite.
- Good ecosystem.
- Suitable learning path while focusing on backend development.

## Consequences

The frontend will be developed entirely with Vue.
