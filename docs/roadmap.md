# 🗺️ Project Roadmap

This document outlines the planned evolution of the portfolio beyond its current frontend implementation.

The roadmap is intended as a high-level vision and may evolve over time as the project grows.

---

# Phase 1 — Portfolio Website ✅

Current goals:

* Build a responsive portfolio using Vue.js and Vite.
* Showcase projects, skills, and experience.
* Provide quick access to GitHub, LinkedIn, and other professional profiles.
* Apply frontend best practices.

Status:

**In Progress**

---

# Phase 2 — Infrastructure

Planned technologies:

* Docker
* Docker Compose
* Nginx
* CI/CD

Goals:

* Containerized deployment
* Reverse proxy configuration
* Automated builds
* Automated deployment pipeline

---

# Phase 3 — Backend Integration

Planned technologies:

* Java
* Spring Boot
* Spring Data JPA
* PostgreSQL

Planned features:

* REST API
* Contact form
* Project data served through the API
* Persistent storage
* Input validation

---

# Phase 4 — Administration Panel

Planned features:

* Authentication
* Secure administration dashboard
* Project management
* Skills management
* Experience management
* Content updates without modifying the frontend

---

# Long-Term Vision

The long-term goal is to transform this portfolio into a complete full-stack application that demonstrates knowledge of:

* Frontend development with Vue.js
* Backend development with Spring Boot
* REST API design
* Database design
* Authentication and authorization
* Containerization
* Deployment
* Software architecture
* Software engineering best practices
