# 🎨 Design System

This document defines the visual identity of the portfolio website.

The objective is to provide a consistent user experience across the application by establishing typography, colors, spacing, and reusable UI principles.

---

# Design Principles

The portfolio should communicate:

- Professionalism
- Simplicity
- Readability
- Modern design
- Technical focus

The interface should remain minimal and avoid unnecessary visual distractions.

---

# Visual Style

The visual style is inspired by modern developer portfolios with:

- Dark theme
- High contrast
- Clean typography
- Spacious layouts
- Subtle animations
- Minimalistic components

# Shadows

Cards and interactive elements should use soft shadows.

Heavy shadows should be avoided.

---

# Icons

Library:

- Lucide Icons

Style:

- Outline
- Consistent stroke width
- Minimalistic

---

# Buttons

Buttons should:

- Use the accent color.
- Include subtle hover animations.
- Preserve accessibility contrast.
- Have generous padding.

---

# Cards

Cards should:

- Use the surface color.
- Have rounded corners.
- Include subtle hover transitions.
- Never use heavy borders.

---

# Animations

Animations should be subtle.

Examples:

- Fade In
- Slide Up
- Hover Scale
- Smooth Scrolling

Animations should enhance the experience without distracting from the content.

---

# Layout

Desktop

Two-column layout.

- Fixed left sidebar.
- Scrollable content on the right.

Mobile

Single-column layout.

- Top header.
- Vertical content.
- Footer at the bottom.

---

# Accessibility

The interface shall:

- Meet WCAG AA contrast guidelines.
- Be fully keyboard navigable.
- Respect reduced motion preferences.
- Use semantic HTML whenever possible.
