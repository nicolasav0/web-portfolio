# 🎨 Design System

This document defines the visual language of the portfolio.

The objective is to ensure consistency across every page and reusable component.

---

# Design Principles

The portfolio should communicate:

- Professionalism
- Simplicity
- Clean engineering
- Modern aesthetics
- Readability

The interface should remain minimal and content-focused.

---
