# Documentation

This directory contains the technical documentation for the portfolio project.

## Structure

architecture.md
Current system architecture.

roadmap.md
Project roadmap and planned features.

decisions/
Architecture Decision Records (ADRs).

diagrams/
Architecture and design diagrams.

## Documentation Principles

The documentation follows these principles:

- Architecture documents describe the current implementation.
- Roadmap documents describe planned work.
- ADRs record important technical decisions and are never rewritten.
- Git history tracks document evolution.
