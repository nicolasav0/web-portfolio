# 🚀 Portfolio Website - [nicolasav.com](https://nicolasav.com)

A personal portfolio website built with Vue.js and Vite, designed to showcase my projects, skills, and experience through a clean, responsive, and modern interface.

---

## 🧠 About the Project

The goal of this project is to create a professional portfolio that showcases my work and serves as a central place to explore my projects, GitHub repositories, and professional profiles.

It is also an opportunity to apply frontend best practices, including:

* Component-based architecture
* Responsive design
* Clean and maintainable code
* Accessibility considerations
* Modern UI/UX principles

> **Note:** The project is currently frontend-only. A backend and database may be added in future iterations to support features such as a contact form, project management, analytics, or a blog.
